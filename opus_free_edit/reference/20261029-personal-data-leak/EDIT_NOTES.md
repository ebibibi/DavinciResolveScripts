# 編集ノート：個人情報が漏れたら、まず何をする？（2026-10-29 収録）

## この動画は何か・誰向けか

- **内容**: 「あちこちから個人情報が漏れた」というニュースを見て不安になった人に向けて、
  ① まず何が漏れたかを（メールのリンクではなく公式サイトから）確かめる、② 漏れた情報の種類ごとにやること
  （パスワード／カード／住所・電話・メール／免許証の画像）、③ 普段からの対策（使い回しをやめる → パスワードマネージャー
  → パスキー）、④ 今日やる3つ、を順に話す回。デッキ `personal-data-leak-response` を見ながらの収録（グリーンバック）。
- **対象**: ITに詳しくない一般の人が中心。ただしチャンネルの常連（IT技術者）向けに AD／NTLM／Windows Hello の話も少し入る。
- **トーン**: 不安を煽らず「落ち着いて、これをやれば大丈夫」。テロップも✅も本人の言葉から作り、事実は足していない。

## 主な判断

### 削ったもの
- **冒頭の挨拶「はいどうもみなさんこんにちは。胡田です。」**（7.0–8.5）: 勝ちパターンどおり、1秒目から問いとスライド1（「あなたの個人情報が漏れたら、どうする？／パスワードを変える。そして、パスワードをやめる。」）を出すため。
- **「すごく不安に感じたり…私がわかりやすくお伝えしていきたい」**（35.5–52.9）: 直前の「困っている方いると思う」と同じ内容で、答えを先に出すために削った。
- **「この辺りの話を今日はしていきたい」**（353–355）: 直後の指示セリフ「というわけで、今日は具体的に…」と重複。
- **スライド送りの無言**（10〜30 秒×10 か所）、**言いよどみ・「はい。」「あの、うん。」**、編集指示の発言すべて。
- **発話の中の無音**: 単語タイムスタンプを信用せず、音声レベル（ソースの話声レベル −20 dB）で 0.4 秒を超える無音を島の内部でも切った。
  これで「免〜許証」（Whisper が 1.8 秒の1語にしていた）、「その上で対策をね、」の後の間などが消え、約 23 秒短くなった。
  間の残し方は「0.45 秒以下の息継ぎはそのまま、それ以上は前 0.08 秒・後 0.15 秒だけ残す」。
- `check_silence.py` は 0 件（えびフライ・スティンガー・エンドカードを除外）。

### 残したもの（迷ったが残した）
- **HTMLメールの昔話**（約 30 秒）: 脱線気味だが「リンクを踏まない」を腹落ちさせる話で、えびフライのツッコミの入れどころにもなる。
- **AD／NTLM／Kerberos／Windows Hello の話**（約 85 秒）: 一般の視聴者には遠いが、本人が視聴者に断ったうえで話しており、
  チャンネルの常連（IT技術者）には価値がある。顔のみレイアウトにテロップ2枚とツッコミを入れて重く見えないようにした。
- **「私はここまで至ったことがないので、自分でやったことはない」**（免許証の部分）: 正直さが信頼につながるので残した。

### 試してやめたこと
- **スライドのテロップ化**: スライド4（リスト型攻撃の図）とスライド5（偽サイトでは自動入力されない）は、最初テロップを出す設計にしたが、
  それだと 30〜47 秒も顔だけになり、図があるスライドを見せられない。テロップを外してスライドを見せた。
- **「今日やる3つ」の✅**: スライド9がまさにその3項目なので、✅で顔だけにするより、スライドを出した方が良いと判断して外した。
- **えびフライ挿入中の映像**: 最初はスライド送りの長い間（366–384 秒）を使ったが、うつむいてスライドを見ている絵だったので差し替えた。
- **session.webm（スライドの入場アニメーション）**: 行が順に出るアニメは最大 12 秒かかり、話の進みと合わない箇所があるため使わず、静止画＋短いフェードにした。
- **章カード（大きなバナー）**: 顔の左に出すと頭にかかるので、トラッカーの現在行を明滅させる方式にした。
- 7 本のえびフライは1回ずつ生成（Gemini 7 リクエスト、撮り直しなし）。「お金はマズい！」は dark ポーズ（黒い姿）で、少し怖いが場面には合うので残した。

## 次回スクリプト化できそうな手順

1. **動画内の編集指示の検出**: 「編集で」「カットして」「使ってほしい」「スキップ」「アゲイン」「もう一回いきます」などの正規表現で候補を出し、前後 30 秒を表示する。今回の5件はすべてこの語で拾える。
2. **カッター**（`work/scripts/timeline.py`）: 単語の島＋島内部の無音分割＋長い単語の音声レベル補正＋フレーム格子へのスナップ。EDL のブロック（元素材の範囲）を書くだけで動く。
3. **えびフライ挿入中の「聞いている絵」探し**（`find_react.py`）: 無音区間ごとに頭の高さと動きを測って候補を出す。最後の目視だけ人が要る。
4. **レイアウト計画**（`plan.py`）: テロップ・✅がある所は顔、スライドがある所は FULL/SPLIT を交互、同じレイアウトの連続を避ける、最短 1.2 秒。
5. **字幕**（`captions.py`）: 誤認識辞書（今回の約 40 件はこのチャンネル共通で再利用できる）＋ janome 改行＋2行ページ分割。
6. **YouTube の章**（`make_meta.py`）: ブロック ID から final の時刻を計算するので、編集を変えても章がずれない。
7. **QA 一式**（無音・ステレオ・フラッシュフレーム・静止区間）を1コマンドにまとめる。

## s1「AIに週690件 指示してたら 血圧160/109」
- 誰向け: AIエージェントを夜まで回している IT 技術者
- フック: 見出し「AIに週690件 指示を出してたら／血圧160/109で病院へ」＋第一声「AIと一緒にガンガン働きすぎて、体を壊しかけております」
- 拍: 告白 → 690件・夜9時台（グラフ）→ えびフライ e01「週に690件！？働きすぎ！」→ しかも夜9時〜朝5時で185件 → 「寝てる間に進めておきたいじゃないですか」（共感）→ 血圧上がる・頭と胸 → 160/109（巨大数字）→ 「痛かったらすぐ救急車」→ 薬と睡眠薬 → 締め「分かりきった話でありますが、AIは疲れず、人間は疲れる」
- 終わり: 「人間は疲れる」で切る（冒頭の「働きすぎて」にループ）
- 注意書き: 医療の区間に「※個人の記録です。体のことは医師の判断に従っています」

## s2「AIを20並列にしたら 人間が詰まった」
- 誰向け: Claude Code 等を並列で回している人
- フック: えびフライ n01「AIを20個同時に動かしたら、最強じゃない？」（視聴者の素朴な期待）→ 本人「今だと10とか20とか並行でさばけちゃう」→「AIはガンガン働いてるけど、私が全然ついていけなくて」
- 拍: 未完了400件近く・返事待ち47件（数字）→ e06「どうしてそんなに溜まっちゃったの？」→ 原因: 私だけが判断（図: AI多数→人間1人）→ 1人で受けたら溜まるのは当たり前 → AIの提案は「9時以降は使わない」→ でも止めるのはもったいない → 直し方3つ（完了条件で自動で閉じる／返事できない時は推奨案で進む・取り消せないもの以外／定期ジョブは1日1回の報告）→ 締め「人に任すのができないタイプ」「明らかにAIの方が私より優秀ですから、もっと任せる仕組みを作らないといけない」
- 50〜60%の転換: 「止めるのはもったいない」で「AIを減らす」から「流れを直す」へ

## s3「AI疲れ、自分の数字で気づける？」
- フック: えびフライ n02「AI疲れって、自分で気づけるの？」＋見出し
- 拍: 血圧計が Wi-Fi で自動記録 → すぐ気づける仕組みを作ってあった → 飲むべき時にすぐ飲み始められた → 自分の数字を見るべき → AIに何件・何時台・生活リズム（彼の数字を並べる）→ 時計で睡眠も → 締め「お前は自分のことやれよって感じだと思うので、私は私でそうやります」
- 注意書き: 「※個人の記録です。胸の痛み・頭痛など症状があれば、仕組みを直すより先に病院へ」（デッキのスライド12の文言）
